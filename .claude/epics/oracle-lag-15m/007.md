# Task: Gamma discovery unit tests

## Description

Vitest unit tests for `listUpDownMarkets()` — filter logic against canned Gamma payloads. Does NOT hit the live Gamma API.

## Acceptance Criteria

- [ ] New file `src/mapping/__tests__/gamma.updown.test.ts`
- [ ] Tests cover the filter predicate with canned payloads:
  - [ ] BTC 15m market with `timeToResolution = 10min` and `tags: ['15M']` + slug `btc-updown-15m-...` → **included**
  - [ ] BTC 5m market (slug `btc-updown-5m-...`, tags include `'5M'`) → **excluded** when asked for 15m
  - [ ] BTC 15m market with `timeToResolution = 25h` → **excluded** when `maxTimeToResolutionMin=15`
  - [ ] Already-resolved market (`endDate` in the past) → **excluded**
  - [ ] Wrong-asset market (e.g. `eth-updown-15m-...`) when asked for bitcoin → **excluded**
  - [ ] Market with matching slug but missing `'15M'` tag → **excluded** (belt-and-braces check)
  - [ ] Empty `markets` array in event → handled without error
  - [ ] `outcomePrices` JSON string parsed correctly: `'["0.505","0.495"]'` → `[0.505, 0.495]`
  - [ ] `clobTokenIds` JSON string parsed correctly
  - [ ] `yesTokenId` / `noTokenId` aliases set correctly (yes = UP, the first element)
- [ ] Tests use `vi.useFakeTimers()` + `vi.setSystemTime()` to control `Date.now()` so `timeToResolution` math is deterministic
- [ ] Network calls are mocked — either `vi.mock('node-fetch')` / `globalThis.fetch` or factor the fetch out of `listUpDownMarkets` into a parameter for injection
- [ ] `npx vitest run src/mapping/__tests__/gamma.updown.test.ts` passes

### Mocking the fetch
Easiest approach — refactor `listUpDownMarkets` to accept an optional fetcher parameter for tests:

```ts
export async function listUpDownMarkets(
  opts: {asset, lifetime, maxTimeToResolutionMin},
  fetcher: typeof fetchRecentCryptoEventsRaw = fetchRecentCryptoEventsRaw,
): Promise<UpDownMarket[]> { ... }
```

Tests pass a mock fetcher that returns the canned payload. Production code uses the default.

### Time control
```ts
beforeEach(() => {
  vi.useFakeTimers();
  // Pin "now" to 2026-04-12T14:50:00Z — 10 minutes before the 15m market ends at 15:00
  vi.setSystemTime(new Date('2026-04-12T14:50:00Z'));
});
afterEach(() => vi.useRealTimers());
```

With that pin, the 15m market has `timeToResolution = 10min` → included when `maxTimeToResolutionMin ≥ 10`.
