## Technical Details

### Endpoint
- URL: `wss://ws-live-data.polymarket.com`
- No auth

### Subscribe frame (send after `open`)
```json
{
  "action": "subscribe",
  "subscriptions": [{"topic": "crypto_prices_chainlink", "type": "update"}]
}
```

### Incoming message shape (verified live 2026-04-11)
```json
{
  "connection_id": "bqQotf6DrPECG0g=",
  "payload": {
    "symbol": "btc/usd",
    "value": 72745.63677585311,
    "full_accuracy_value": "72745636775853115000000",
    "timestamp": 1775919469000
  },
  "topic": "crypto_prices_chainlink",
  "type": "update",
  "timestamp": 1775919470517
}
```

- Filter: only process messages where `topic === 'crypto_prices_chainlink' && type === 'update'`
- `payload.timestamp` (ms) — oracle publish time
- outer `timestamp` (ms) — RTDS relay time
- Use `payload.value` (float) as the price; `full_accuracy_value` is for precision-critical downstream work (ignore for now)
- Symbols of interest: `btc/usd`, `eth/usd`, `sol/usd`, `xrp/usd`, `doge/usd`, `bnb/usd`, `hype/usd`
- Default to subscribing to all of them; let the scanner filter

### Ringbuffer shape
Per-symbol circular buffer of `{value: number, oracleTs: number, receivedAt: number}`. `pushTick` appends; old entries drop off when the buffer hits capacity (default 600 ≈ 10 min at 1/s).

### getMoveSince semantics
```ts
getMoveSince('btc/usd', 5000)
// Returns the move from the oldest tick within `now - windowMs` to the newest tick:
// { oldPrice: 72741.12, newPrice: 72748.73, pctMove: 0.01046, ticks: 5 }
// or null if buffer has <2 ticks or all ticks are older than windowMs
```

The `windowMs` is a lookback from `Date.now()` (wall clock), not from the newest oracle timestamp — we care about real reaction time.

### Lifecycle
- `start()` is called once from the worker on boot
- `stop()` is called from the worker's SIGTERM handler before `closeRedis()`
- Auto-reconnect keeps the feed live across transient network blips
- On hard failure (5 consecutive reconnect attempts fail), log `chainlink_feed_fatal` but do not exit — the worker supervises
