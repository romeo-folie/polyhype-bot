# Task: Oracle-lag config schema

## Description

Add 7 `ORACLE_LAG_*` env vars to `src/shared/config.ts` (Zod schema) and document them in `.env.example`. All defaults must be shadow-safe (`ORACLE_LAG_ENABLED=false`).

## Technical Details

### New env vars
| Name | Type | Default | Purpose |
|---|---|---|---|
| `ORACLE_LAG_ENABLED` | boolean | `false` | Master kill-switch. When false, scanner runs in shadow mode (log candidates, never fire). |
| `ORACLE_LAG_MIN_MOVE_PCT` | number | `0.07` | Minimum Chainlink move percentage over the lookback window to consider entry. |
| `ORACLE_LAG_MOVE_WINDOW_SEC` | number | `5` | Lookback window (seconds) for computing the Chainlink move. |
| `ORACLE_LAG_MIN_TIME_LEFT_MIN` | number | `5` | Skip entry if time to resolution is under this many minutes. |
| `ORACLE_LAG_MAX_ENTRY_PRICE` | number | `0.62` | Skip entry if market price on the signal side exceeds this (fee math breaks). |
| `ORACLE_LAG_STAKE_USD` | number | `5` | Fixed per-entry stake — bypasses Half-Kelly. |
| `ORACLE_LAG_MAX_TRADES_PER_HOUR` | number | `10` | Hard cap on live entries per hour. When flipping live, operator will lower this to 3 for first 24h. |

### Pattern to follow
Look at existing `UPDOWN_*` vars in `src/shared/config.ts` for the exact Zod pattern, variable naming, and how booleans are coerced. Copy that style exactly. Put the new block near the existing `UPDOWN_*` block for grep-ability.

### `.env.example` section
Add to the file after the existing `UPDOWN_*` section:
```
# --- Oracle-Lag Scanner (BTC Up/Down 15m, Chainlink oracle-lag sniper) ---
# Master switch. Ship dark; flip to true only after shadow-log review passes.
ORACLE_LAG_ENABLED=false
# Minimum Chainlink BTC move % over the lookback window to consider entry
ORACLE_LAG_MIN_MOVE_PCT=0.07
# Lookback window in seconds for the Chainlink move computation
ORACLE_LAG_MOVE_WINDOW_SEC=5
# Skip entry if time to market resolution is below this many minutes
ORACLE_LAG_MIN_TIME_LEFT_MIN=5
# Skip entry if market price on the signal side exceeds this (fee math breaks above ~0.62)
ORACLE_LAG_MAX_ENTRY_PRICE=0.62
# Fixed per-entry stake — bypasses Half-Kelly (edge is timing, not probability)
ORACLE_LAG_STAKE_USD=5
# Hard cap on live entries per hour
ORACLE_LAG_MAX_TRADES_PER_HOUR=10
```
